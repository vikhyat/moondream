# Notebooks

This folder currently contains `RepEng.ipynb` (control vectors for steering
model behavior).

There is no `finetune.ipynb` here: links to
`notebooks/finetune.ipynb` (also mirrored on Hugging Face) 404 because no such
notebook is shipped in this repo.

To finetune instead, use the runnable scripts in
[`examples/quickstart/finetune/`](../examples/quickstart/finetune/)
(e.g. `train_ballholder_detect.py`) and see the
[Finetuning guide](https://moondream.ai/c/docs/finetuning).
